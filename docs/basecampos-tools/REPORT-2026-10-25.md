## CORRECTION (10:05) - run 1 was NOT a firmware rejection
Experiment ci-debianroot (same CI Image+dtbs in the same signed FIT, Debian root=/dev/mmcblk0p5) BOOTED: ~/duet/basecampos/p2test-ci-debianroot.log shows `Linux 6.12.50-stb-cbm #1-NixOS` (the CI kernel) running Debian at 10:00 with the panel (card1-DSI-1), GPU (card0/renderD128) and input devices up; only 1 module loaded (no matching modules = no Wi-Fi), harmless. Afterwards p2 showed prio 0 tries 0 success 0 just like after run 1: vboot zeroes the priority at the NEXT boot when a kernel used its tries without marking success, so prio 0 proves nothing about rejection. The real cause of run 1: `root=LABEL=home` - without an initrd the kernel cannot resolve LABEL= (only /dev/..., PARTUUID, PARTLABEL), so it panicked ("Cannot open root device"), panic=10 rebooted, firmware fell back to KERN-B (~2 min total). FIX: cmdline root=/dev/mmcblk0p1 rootfstype=btrfs rootflags=subvol=@basecampos,noatime ... (p1 = the btrfs LABEL=home partition). Also: the NixOS kernel is fine on this board incl. DSI panel + GPU, and the depthcharge/FIT/signing path is proven for the CI Image.

## 10:40 ROOT CAUSE of runs 1-3 FOUND: `noatime` in rootflags
The diag initramfs (label initramfs-diag; log /var/log/initramfs-diag.log, kept in ~/duet/reports/basecampos/initramfs-diag.log) shows the CI kernel mounts /dev/mmcblk0p1 fine with ro, subvol=@debtest, subvol=@basecampos and rw,subvol=@basecampos,noatime (rc=0, partitions are ready at 0.90 s, before /init at 0.91 s) - but via busybox `mount -o`, which turns noatime into the VFS flag MS_NOATIME. On the kernel command line `rootflags=` is passed RAW as the filesystem data string, and btrfs does not know `noatime` as a data option -> mount fails (EINVAL) -> panic -> panic=10 reboot -> firmware falls back to KERN-B. All my run 1-3 cmdlines (and the @debtest one) contained `noatime` (run 1 additionally LABEL=). Fix: rootflags=subvol=@basecampos only (atime stays default; NixOS' fstab remounts / with noatime later). Run 4 = same BasecampOS blob + init=/diag-init without noatime.
